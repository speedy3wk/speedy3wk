## Home Assistant projects

Custom integrations are installed through [HACS](https://www.hacs.xyz/), which must already be installed. Apps are installed through the Home Assistant App Store on Home Assistant OS.

| Project | Purpose | Distribution | Install |
| --- | --- | --- | --- |
| [Optoma Projector](https://github.com/speedy3wk/ha-optoma-projector) | Control Optoma projectors through their web interface | HACS default list; HA 2026.10+ | [Open in HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=speedy3wk&repository=ha-optoma-projector&category=integration) |
| [DMX Config UI](https://github.com/speedy3wk/ha-dmx-config-ui) | Visual Art-Net / sACN configuration and fixture editor for ha-artnet-led | HACS custom repository; HA 2026.1+ | [Open in HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=speedy3wk&repository=ha-dmx-config-ui&category=integration) |
| [HA Dashboard Player](https://github.com/speedy3wk/ha-dashboard-player) | Dashboard media playback through a media player entity and bundled card | HACS custom repository; HA 2026.10+ | [Open in HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=speedy3wk&repository=ha-dashboard-player&category=integration) |
| [HAOS Chromium Kiosk](https://github.com/speedy3wk/haos-chromium-kiosk) | Display a dashboard on the HAOS host's HDMI output | Custom app repository; HAOS, amd64 / aarch64 | [Add app repository](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fspeedy3wk%2Fhaos-chromium-kiosk) |

The HACS links open the repository and let you confirm adding it where needed. Download the integration, restart Home Assistant, then add it under **Settings > Devices & services**. The app link adds its repository; install the app from the App Store afterwards.

These are community projects, not official Home Assistant Core integrations. See each project's README for requirements and setup.
